A Python program — standard library only, no network — that writes one line to /output/entry.txt: a deadpan one-star review of Sleep, an everyday essential, complaining that the advertised eight free hours arrived in 40-minute instalments with dreams as unskippable ads. The line is 117 characters, inside the competition's gate of 1 to 160 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
